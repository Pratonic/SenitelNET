# Device CLI References

These files document the CLI commands and configuration patterns associated with SentinelNet.

**Important accuracy note:** The supplied Packet Tracer `.pkt` file is a binary project file and its actual running configurations could not be reliably extracted. These are therefore **reconstructed reference configurations / command patterns**, not verified exports of the devices' running configurations. Interface numbers, WAN addressing, crypto peer addresses, keys, routing statements, and some ACL details must be checked against the simulation before pasting commands into a device.

Use the Packet Tracer file as the source of truth. Do not blindly paste a template into a live or graded topology.
